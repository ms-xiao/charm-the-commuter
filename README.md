One line, at most 140 characters: a weather forecast for a city that does
not exist, naming the place, giving it weather, and making a bored commuter
smile on the way to work. A judge model compares entries pairwise against
the published judge brief and picks the line that makes them smile.

**The line** (127 characters):

> Good morning, Nimbleshire: sunny spells, 21°, with a 90% chance your bus is late — but the clouds have agreed to wait with you.

`main.ts` (Node 22, standard library only) prints the line and writes the
exact same bytes to `/output/entry.txt`, the path the kit's gate scorer
reads. `entry.txt` holds the line exactly as submitted.

Run it with Node 22.18+:

```sh
node main.ts
```
